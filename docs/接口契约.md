# 后端接口契约

所有接口前缀为 `/api`，统一返回 JSON。当前版本不提供内置登录，部署者必须在反向代理、VPN、防火墙或 NAS 权限层限制访问。

## 通用约定

成功通常为：

~~~json
{ "ok": true, "data": {} }
~~~

业务失败可能仍返回 HTTP 200，必须检查 `ok`。输入错误通常为 400，不存在为 404，更新冲突为 409，未处理异常为 500。API Key 明文只在写入或探测请求中出现，读取接口只返回 `hasToken` 和掩码。

## 接口列表

| 方法 | 路径 | 作用 |
|---|---|---|
| GET | /api/health | 健康检查 |
| GET | /api/bootstrap | 返回站点预设与程序版本 |
| GET | /api/state | 获取站点、汇总、设置和凭据掩码 |
| GET | /api/version | Docker 查询 Git 标签；飞牛查询最新 GitHub Release |
| POST | /api/refresh | 刷新全部或单个站点 |
| GET | /api/usage?id=&range=&force=1 | 读取单站点用量；force=1 跳过短缓存 |
| POST | /api/probe | 探测站点，不落库 |
| POST | /api/station | 新增或修改站点 |
| DELETE | /api/station?id= | 删除站点 |
| POST | /api/license/activate | 激活与当前安装编号绑定的完整功能许可证 |
| POST | /api/settings | 保存通用、推送或代理设置 |
| POST | /api/notify/test | 测试指定推送渠道 |
| GET/POST | /api/update | 读取状态或开始在线更新 |
| POST | /api/update/file | 上传并安装 Git Bundle 本地更新包 |
| GET | /api/export | 导出加密配置 |
| POST | /api/import | 导入配置 |
| POST | /api/alerts/clear | 清空告警记录 |

## 刷新

页面启动顺序为 `/api/bootstrap` → `/api/state` → `/api/refresh` → `/api/usage`。

`/api/refresh` 接收 `{}`，刷新所有启用且 `queryMode=auto` 的站点；接收 `{ "id": "站点ID" }` 时显式刷新该站点。返回与 `/api/state` 相同的数据并包含 `elapsedMs`。

## 用量

`/api/usage` 的 `range` 支持 `today`、`yesterday`、`7d`、`30d`。`force=1` 会删除当前站点短缓存后重新请求，适合用户点击“更新用量”。明细可用时返回 `detail`、`complete`、`today`、`trend`、`models` 和 `logs`。周期汇总接口也返回 `detail:true`，但 `requestDetail:false` 且 `logs:[]`；只提供余额汇总时返回 `detail:false`。任何 `null` 指标都代表未知，前端不得按零汇总。

## 站点写入结构

`POST /api/station` 接收 `{ "station": {...} }`。常用字段如下：

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| id | string | 更新时必填；新增时省略 |
| name、baseUrl | string | 显示名称与站点根地址 |
| token | string | 新凭据；更新时空字符串表示保留旧值 |
| enabled | boolean | 是否参与刷新与汇总 |
| queryMode | string | `auto`、`manual` 或 `paused` |
| preset | string | 内置模板 ID 或 `custom` |
| queryPath、quotaPath | string | 自定义余额请求 URL 与必填余额路径 |
| rawPerUnit、unitCurrency | number/string | 余额换算除数与原始币种 |
| usageEndpoint、usageMap | string | 自定义周期用量接口与字段映射 |

当 `usageEndpoint` 非空时，`usageMap` 必须是含 `periods` 和 `metrics` 的 JSON。站点地址、计费接口和用量接口均为服务端主动请求目标，只允许配置可信地址。

## 写入

- POST /api/probe：探测但不落库，HTTP 200 时也要检查 ok。
- POST /api/station：不传 id 表示新增；空 token 表示保留已有密钥。
- POST /api/license/activate：接收 `{ "code": "签名激活码" }`；成功后返回完整 `/api/state`。免费版新增或导入后超过 2 个站点时返回 HTTP 403 和 `code: LICENSE_REQUIRED`。
- POST /api/settings：支持刷新间隔、阈值、汇率、推送渠道、更新代理和备用仓库地址。免费版提交 `notify` 时返回 HTTP 403 和 `code: LICENSE_REQUIRED`。
- GET /api/export 与 POST /api/import：导出文件包含加密密钥，仍属敏感数据。

导入在不同设备之间迁移时必须沿用原 `APP_SECRET`。否则配置本身可以读入，但加密凭据无法解密。

## 程序更新

`GET /api/version` 返回 `current`、`latest`、`updateAvailable` 和 `source`。Docker 版的 `details` 最多包含 20 条当前提交到最新版本标签之间的提交标题；飞牛版从 GitHub Release 返回 `releaseNotes`、`fpkUrl` 和 `fpkSize`，下载地址只接受可信的 GitHub HTTPS 地址。

`POST /api/update` 的 `source` 可为 `github` 或 `mirror`。使用备用仓库时，必须同时保存 `mirrorUrl`：

~~~json
{
  "source": "mirror",
  "proxyUrl": "",
  "mirrorUrl": "https://可信镜像站/用户/api.git"
}
~~~

备用仓库必须提供 `main` 分支并同步 `v1.2.3` 格式的版本标签。地址仅允许 HTTP/HTTPS，不能包含账号或密码。

飞牛版调用 `POST /api/update` 时不接收下载地址，而是重新读取官方 GitHub Release，只下载与最新版本名称完全匹配的 FPK，然后调用飞牛应用中心覆盖升级。更新状态会包含下载进度；配置和历史保留在应用数据目录。

`POST /api/update/file` 直接以请求体上传 `.bundle` 文件，请求头 `X-Update-Filename` 填 URL 编码后的文件名，`Content-Type` 为 `application/octet-stream`，上限 100 MB。服务验证包内项目名、版本、Git 历史和工作区状态，仅执行快进更新；配置、历史和 `.env` 不在 Git 更新范围内。

## 推送设置

推送属于完整功能，一次性支付 10 元激活后可用。免费版调用推送设置或测试接口会返回 HTTP 403 和 `code: LICENSE_REQUIRED`，后台定时任务也不会发送；此限制适用于 Docker、飞牛和 Android。

`POST /api/settings` 的 `notify` 示例：

~~~json
{
  "notify": {
    "pushTime": "09:00",
    "channels": {
      "bark": { "enabled": true, "url": "https://api.day.app/你的Key" },
      "serverChan": { "enabled": false, "sendKey": "SCT..." },
      "pushPlus": { "enabled": false, "token": "token" },
      "telegram": { "enabled": false, "botToken": "123:ABC", "chatId": "123456" },
      "webhook": { "enabled": false, "url": "https://example.com/hook" }
    }
  }
}
~~~

空凭据表示保留已保存值，不会清空。`GET /api/state` 只返回 `enabled`、`xxxConfigured` 和 `xxxMask`。测试接口接收 `{ "type": "bark" }`；可用类型为 `bark`、`serverChan`、`pushPlus`、`telegram`、`webhook`。

## 前端注意事项

1. 时间戳在浏览器按 `Asia/Shanghai` 格式化。
2. `balanceAvailable:false` 不显示金额、不参与余额汇总。
3. `stale:true` 表示展示旧数据，不能当作新查询成功。
4. 凭据输入框留空时保留服务端已保存值。
