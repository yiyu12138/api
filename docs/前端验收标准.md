# 前端实现与验收标准

前端使用原生 HTML、CSS 和 JavaScript，无构建步骤或外部 CDN。

## 页面结构

- 桌面端固定侧栏，主内容铺满剩余宽度。
- 移动端固定底部导航：总览、添加、管理、推送、设置。
- 添加站点、站点管理、推送、通用设置、更新和文档均为主内容页面。
- 设置页下方依次提供反馈、推荐链接、API 文档、程序更新、GitHub 和外观。

## 状态规则

| 状态 | 行为 |
| --- | --- |
| 启用 + 自动 | 页面打开、定时任务和手动操作均可查询 |
| 启用 + 仅手动 | 只响应显式测试、刷新或更新用量 |
| 暂停 / 停用 | 不查询，不参与余额与用量汇总 |
| 查询失败 | 保留旧值并标记过期，不按零汇总 |
| 字段缺失 | 显示未知或“已知部分” |

## 交互与可访问性

- 每次重渲染前调用 `snapshotDrafts()`，避免输入丢失。
- 所有用户数据通过 `esc()` 插值；密钥使用密码输入。
- 弹窗包含 `role=dialog`、焦点进入、Tab 循环、Escape 关闭和焦点恢复。
- 图标按钮提供可访问名称；移动端触控目标不小于现有底部导航规格。
- `prefers-reduced-motion` 下禁用非必要动画。
- 深色、亮色和跟随系统同时更新页面与浏览器主题色。

## 检查

```bash
npm test
node --check public/app.js
node --check server/index.js
node --check server/probe.js
```

最后使用桌面与手机视口检查总览、站点表单、文档、反馈弹窗和四个用量时间范围，并确认控制台没有错误。
